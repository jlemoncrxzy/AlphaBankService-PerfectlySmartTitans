# Альфа-Бизнес — новостная аналитика

Демонстрационный frontend на React и JavaScript. При запуске без настроенного API используются локальные демонстрационные данные.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка: `npm run build`. Для просмотра собранной версии: `npm run preview`.

## Просмотр мобильной версии

Отдельный мобильный адрес не нужен: адаптивная компоновка включается автоматически при ширине окна до 600 px. Запустите `npm run dev`, откройте адрес Vite в Chrome или Edge и включите панель устройств сочетанием `Ctrl+Shift+M`. Выберите модель телефона или задайте ширину экрана вручную.
