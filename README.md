# Alfa Insight MVP

AI-агент для руководителей крупного бизнеса: персонализированная интерпретация
внешних новостей и аналитики Альфа-Банка по каждому клиенту. Многошаговый
пайплайн (план → сбор контекста → поиск → ранжирование → LLM-интерпретация →
самопроверка → сводка) с полной трассировкой шагов и журналом обращений
к инструментам.

## Стек
- Python 3.11, FastAPI, SQLAlchemy 2.0, SQLite
- JWT-аутентификация (passlib/bcrypt), RBAC: viewer / analyst / admin
- LLM: DeepSeek-V4.1-Flash (единственная разрешённая по ТЗ); при отсутствии
  ключа — детерминированный heuristic-фоллбэк (см. `THIRD_PARTY_NOTICES.md`)
- Фронт: ванильный HTML/JS без сборки

## Требования к окружению
- Python 3.11+ **или** Docker 24+ / Docker Compose v2
- Git
